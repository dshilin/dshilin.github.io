# Конфиденциальность

Я размещаю этот блог на GitHub Pages.

## Технические данные хостинга

При посещении сайта GitHub Pages записывает и хранит IP-адрес посетителя в целях безопасности. Эту обработку выполняет GitHub как поставщик хостинга. Отдельный журнал IP-адресов в коде блога не ведётся.

Условия обработки данных инфраструктурой хостинга описаны в [политике конфиденциальности GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). Сведения о записи IP-адресов приведены в [документации GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection).

## Настройки оформления

Выбранная светлая или тёмная тема сохраняется в браузере с помощью localStorage. Это позволяет использовать выбранное оформление при следующем посещении сайта.

## Внешние ссылки

При переходе по внешней ссылке начинают действовать правила соответствующего сайта. Например, обработку данных на github.com описывает политика GitHub.
