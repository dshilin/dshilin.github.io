# 404 — проверка

Существовавший стандарт Hextra уже генерировал `404.html` с английским сообщением, без ссылок и без стилевого оформления блога. Предложенный вариант сохраняет компактность и добавляет русское сообщение, две рабочие ссылки, адаптивную светлую/темную тему и фокус клавиатуры.

Проверить рендер обеих конфигураций темы, ссылки и наличие `404.html` в output; затем передать страницу Дмитрию. Файл шаблона не включать в production до решения о точной версии; эта ветка не выполняет deployment.

## Результаты проверки — 2026-10-30

- Hugo 0.161.1 успешно создал `404.html` как в production-сборке, так и в сборке с черновиками.
- Локальный просмотр подтвердил точный русский текст и ссылки `/` и `/blog/`. На desktop и viewport 390px карточка не переполняет ширину; в светлой и выбранной темной теме сохраняются читаемый контраст и видимые CTA. Фокус клавиатуры задан стилем `:focus-visible`.
- Прямое открытие статического файла `404.html` в локальном HTTP preview возвращает обычную страницу; HTTP-статус 404 при выдаче GitHub Pages здесь не подтверждался. Сборка/публикация на GitHub не выполнялась.
- Статус этой страницы инициализируется layout-файлом, поэтому Hugo front matter `draft: true` применить нельзя. Она остается только в текущей review-ветке до отдельного решения автора.

## Авторское решение — 2026-10-30

- Дмитрий ответил: «Утвердить эту версию».
- Утвержден текст и вид страницы из `01-404-draft.md` / `layouts/404.html`. Это утверждение версии, не разрешение на deploy. HTTP-статус на GitHub Pages остается непроверенным.
