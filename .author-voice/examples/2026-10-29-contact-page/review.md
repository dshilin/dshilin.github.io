Дата: 2026-10-29, Europe/Saratov. Статус: незавершенный черновик, нужен выбранный автором прямой канал связи.

Задача: после принятия упрощенной структуры продолжить проверку страниц по одной. Вопрос читателя — как связаться с Дмитрием по работе или материалам блога. Это напрямую поддерживает третий ориентир принятой миссии.

Источник профессионального направления — принятое решение о роли и утвержденный биографический вариант автора. Обсуждение материалов соответствует миссии помочь начать разговор. Прямая почта, Telegram и иной предпочтительный канал не заданы в проверенном контексте; подтвержден только GitHub из hugo.yaml. Ссылка GitHub не заменяет неизвестный контакт для личной переписки.

`01-contact-draft.md` — первое предложение короткого текста, ожидает проверки и дополнения контактными данными. Диагностика copywriting: A. Нет исходной страницы контактов в прочитанном реестре; новый текст не создает коммерческих обещаний и не приписывает достижения.

Прямой вопрос автору — какой канал и конкретный адрес/профиль разрешено указать на странице. Не собирать случайные персональные контакты из сторонних источников вместо выбора пользователя. До ответа страница не готова к публикации. Публичный контент и конфигурация не изменены.
