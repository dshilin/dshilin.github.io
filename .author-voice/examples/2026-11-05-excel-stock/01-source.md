## Уточнения по сравнению с заметками

- 7697 минус 7097 равно 600. Число 599 в подробном разборе исправлено по повторному чтению результата.
- Подсчёт через `sum` проходит множество удалённых строк при каждом вызове. В публичной версии применён `bisect_left`, без переноса неподтверждённых утверждений о скорости.
- `openpyxl.delete_rows` поддерживает удаление диапазона. В пост перенесено документированное ограничение на сопровождение зависимостей, без заявления о том, что метод удаляет только по одной строке.
- В публичной версии вычисляется конец товарной секции, пересчитываются итоги по единицам измерения и заново собирается sharedStrings. Прежние тексты в sharedStrings неприемлемы для публичного обезличенного примера.
- Новая версия обрабатывает XML через ElementTree. Объяснение исходного подхода через регулярные выражения сохранено с указанием различий.
