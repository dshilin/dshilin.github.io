# Промпт задачи подготовки постов Python

Дата: 2026-10-21. Задача: отредактировать предоставленный пользователем промпт запланированной задачи с учетом требования сохранять посты в content/docs/python как черновики с кодом и примерами. Аудитория промпта: исполнитель задачи; аудитория постов уточняется по теме.

01-source.md — исходный промпт, предоставленный пользователем со словами «вот промт, его надо отредактировать».

02-assistant-draft.md — редакция ассистента. Статус: ожидает проверки. Прямое разрешение редактировать не означает одобрения этой версии. Настройки внешней задачи не изменены.

Сохранены требования к программе и доказательствам. Пакет материалов заменен на связный Markdown-пост; добавлены локальный путь, draft: true, код, примеры, авторский архив и явное поведение при отсутствии доступа к локальным файлам. Дополнительные решения ассистента не являются подтвержденными общими предпочтениями автора.
